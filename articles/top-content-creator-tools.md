# Инструменты для качественного стриминга

Качественный контент требует правильного набора инструментов. В этой статье я поделюсь списком программного обеспечения и оборудования, которые я использую для своих трансляций и создания видео.

## Программное обеспечение (Софт)

1. **OBS Studio (Open Broadcaster Software)**
   * Самый популярный инструмент для трансляций. Полностью бесплатный и с открытым исходным кодом.
   * *Моя рекомендация:* Используйте плагин **OBS-WebSocket** для автоматизации сцен.
2. **DaVinci Resolve**
   * Мой основной выбор для монтажа видео и цветокоррекции. Бесплатная версия покрывает 95% задач.
3. **Reaper**
   * Станция для обработки звука в реальном времени. Позволяет наложить качественные VST-фильтры (эквалайзер, компрессор, шумоподавление) перед отправкой звука в ОБС.

### Полезный скрипт для автоматического бэкапа настроек OBS (Bash)

```bash
#!/bin/bash
# Бэкап профилей и сцен OBS
BACKUP_DIR="$HOME/OBS_Backup_$(date +%F)"
mkdir -p "$BACKUP_DIR"
cp -r "$HOME/.config/obs-studio/" "$BACKUP_DIR"
echo "Бэкап настроек OBS успешно создан в $BACKUP_DIR"
```
