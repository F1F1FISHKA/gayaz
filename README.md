# Статический сайт-блог Волшебника-73

Красивый статический сайт-блог для инфлюенсеров и стримеров. Полностью адаптирован под размещение на **GitHub Pages** и работает без внешних баз данных или бэкенд-серверов.

## ✨ Ключевые возможности

1. **Главная страница (Социальный Хаб)**: Стильные интерактивные карточки со ссылками на соцсети с эффектом стеклянного морфизма (Glassmorphism), неоновым свечением и плавными анимациями.
2. **Панель статей (Markdown-ридер)**: Боковое меню со списком статей. Текст статей хранится в обычных `.md` файлах (папка `articles/`), которые динамически загружаются и парсятся на стороне клиента с помощью библиотеки `marked`.
3. **Автоматический трекер стримов**: Сайт периодически проверяет, идет ли сейчас трансляция на YouTube-канале `@волшебник-73`.
4. **Звуковое оповещение (Web Audio API)**: В момент запуска трансляции проигрывается футуристичный киберпанк-звук. Он генерируется прямо в браузере с помощью синтеза частот (без скачивания тяжелых `.mp3` файлов).
5. **Встроенный просмотр**: Кнопка «Смотреть стрим» открывает всплывающее окно (модалку) с видеоплеером YouTube прямо на сайте.
6. **Панель отладки (Debug)**: В правом нижнем углу встроена кнопка «Включить симуляцию», чтобы вы могли в любой момент протестировать появление плашки уведомления и звуковой сигнал.

## 📂 Структура проекта

* `index.html` — основная разметка сайта.
* `style.css` — стили, адаптивная сетка, анимации и шрифты.
* `app.js` — роутинг, логика загрузки статей, авто-проверка стрима, синтезатор звука и управление модальными окнами.
* `config.json` — конфигурационный файл (название блога, био и ссылки на соцсети).
* `articles.json` — индексный список статей (название, теги, дата создания).
* `articles/` — папка с файлами статей в формате `.md` (Markdown).

## 🚀 Инструкция по публикации на GitHub Pages

Чтобы ваш сайт стал доступен в интернете бесплатно, выполните следующие шаги:

1. **Создайте репозиторий на GitHub**:
   * Создайте новый публичный репозиторий (например, с именем `blog`).
2. **Загрузите файлы проекта**:
   * Инициализируйте Git, закоммитьте файлы и отправьте их в созданный репозиторий:
     ```bash
     git init
     git add .
     git commit -m "Initial commit"
     git branch -M main
     git remote add origin https://github.com/ВАШ_НИКНЕЙМ/ИМЯ_РЕПОЗИТОРИЯ.git
     git push -u origin main
     ```
3. **Включите GitHub Pages**:
   * Перейдите во вкладку **Settings** (Настройки) вашего репозитория на GitHub.
   * В левом меню выберите пункт **Pages** (Раздел Code and automation).
   * В блоке **Build and deployment** в выпадающем списке **Source** убедитесь, что выбрано `Deploy from a branch`.
   * В поле **Branch** выберите ветку `main` (или `master`) и папку `/ (root)`.
   * Нажмите кнопку **Save** (Сохранить).
4. **Готово!**
   * Через 1-2 минуты GitHub опубликует ваш сайт. Ссылка на него появится в верхней части страницы настроек Pages (обычно формат ссылки: `https://ваше-имя.github.io/имя-репозитория/`).
